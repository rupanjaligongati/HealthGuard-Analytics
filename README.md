# 🏥 HealthGuard Analytics

A Healthcare Data Analytics project built using **Python**, **Jupyter Notebook**, and **Microsoft Power BI** to generate, clean, analyze, and visualize patient healthcare data through an interactive dashboard.

---

# 📌 Project Overview

HealthGuard Analytics demonstrates the complete data analytics workflow:

- Healthcare dataset generation
- Data quality issue creation
- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Executive KPI creation
- Interactive Power BI Dashboard

This project helps analyze healthcare data and provides insights into patient demographics, BMI, insurance coverage, blood groups, age groups, and city-wise patient distribution.

---

# 🎯 Objectives

- Generate a realistic healthcare dataset.
- Clean and preprocess healthcare data.
- Perform Exploratory Data Analysis (EDA).
- Build executive healthcare KPIs.
- Create an interactive Power BI dashboard.
- Provide meaningful healthcare insights.

# 🚀 How to Run the Project

## Clone Repository

```bash
git clone https://github.com/rupanjaligongati/HealthGuard-Analytics.git
```

## Install Python Packages

```bash
pip install -r requirements.txt
```

## Open the Project

- Run the Jupyter notebooks for data generation, cleaning, and analysis.
- Open `HealthGuard_Analytics_Dashboard.pbix` in Microsoft Power BI Desktop to explore the interactive dashboard.
